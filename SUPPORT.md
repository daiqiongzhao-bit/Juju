# Support

Yuvomi is a solo-maintained open-source project. Pick the channel that fits:

- **Questions & ideas** — [GitHub Discussions](https://github.com/daiqiongzhao-bit/Juju/discussions).
  Feature ideas go to the [Ideas category](https://github.com/daiqiongzhao-bit/Juju/discussions/new?category=ideas);
  issues are reserved for bugs.
- **Bugs** — [open a bug report](https://github.com/daiqiongzhao-bit/Juju/issues/new/choose).
  Please fill in the version and deployment fields — they decide where to look first.
- **Security vulnerabilities** — never a public issue: use
  [private vulnerability reporting](https://github.com/daiqiongzhao-bit/Juju/security/advisories/new)
  (see [SECURITY.md](SECURITY.md)).
- **Setup help** — the [installation guide](docs/installation.md) covers Docker/Podman,
  HTTPS, backups and troubleshooting; the [README FAQ](README.md#faq) answers the most
  common questions.

Expect answers within a few days — this is one person's evenings, not a support desk.
